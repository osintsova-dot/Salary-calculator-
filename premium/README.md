# Speak&Smile · Финансы школы

Локальный редизайн существующего калькулятора. Исходные файлы в родительской папке не изменены. Деплой не выполняется.

## Запуск

`npm install`, затем `npm run dev`. Приложение: http://127.0.0.1:5173.

`npm run lint`, `npm test`, `npm run build` — проверки. `npm run preview` — production-превью.

## Архитектура

- `src/main.jsx` — React-кабинет, навигация, текущие показатели, сценарий роста.
- `src/bridge.js` — адаптер существующих таблиц, секций и доступности диалогов.
- `public/engine.js` — расчётный скрипт, без изменений извлечённый из исходного `../index.html`. Тест сверяет полное совпадение.
- `src/style.css` — дизайн-система, адаптивные состояния и reduced motion.
- `public/newcomers.html`, `otrabotki.html`, `budget.html` — сохранённые рабочие дополнительные страницы с общим оформлением и возвратом в кабинет.

Данные хранятся в localStorage текущего origin. Данные GitHub Pages не копируются автоматически на localhost. Без авторизации BigBen показываются исходные данные и прогноз по тарифу; отсутствующие фактические оплаты обозначены прочерком. Подключение CRM и экспорт остаются оригинальными функциями, не подменены демонстрацией. Во время разработки запросы на отправку данных в бюджет семьи не выполнялись.

В калькуляторе есть действующие финансовые и персональные сведения. Для локального кабинета выставлено `noindex,nofollow`. Open Graph — локальное изображение `public/og.png`; URL следует менять только при отдельно согласованной публикации.

## Источники UI

- shadcn/ui Tabs (MIT): https://ui.shadcn.com/docs/components/tabs — адаптированы стили, сохранён Radix и клавиатурное управление.
- Magic UI Number Ticker (MIT): https://magicui.design/docs/components/number-ticker — адаптирован под русский формат чисел и reduced motion.
- 21st.dev: https://21st.dev/community/components/s/dashboard — исследование композиции dashboard и sidebar, без установки дополнительных шаблонов.
- Motion: появления и числовые переходы. Lucide: единая система иконок.
- Manrope и Geologica: локально поставляемые шрифты через Fontsource.

## Проверки

Пять тестов: неизменность расчётного ядра, тарифная группа, выключенная группа, скидки и переводы из CRM, отсутствие отрицательной суммы на руки. Ручная браузерная проверка: desktop, tablet, mobile, переключение месяца, сохранение, история, квиток, фильтр педагогов, сценарий набора и навигация.
