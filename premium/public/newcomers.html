📞 Что говорить по телефону

1. Приветствие

«Здравствуйте! Это Наталья, школа английского Speak&Smile, Норильск. Удобно сейчас пару минут?»

2. Повод

Осень: «Вы недавно оставляли заявку на английский для ребёнка — звоню по ней, подобрать группу.»
Весна: «Вы весной интересовались английским у нас. Идёт набор на новый год, места есть — актуально ещё?»

3. Уточнить

Для ребёнка какого класса подбираем? Английский учили — школа, репетитор, другая школа или с нуля?

4. Суть

«Небольшие группы по уровню и возрасту, упор чтобы ребёнок говорил. Первый шаг — бесплатная диагностика: смотрим уровень, подбираем группу. Ни к чему не обязывает.»

5. Цель звонка

«Запишу на диагностику? Есть [время А] или [время Б] — как удобнее?» — всегда выбор из двух.

Возражения

Дорого → сначала бесплатная диагностика, потом варианты и рассрочка.
Нет времени → подберём расписание, есть вечер и выходные; диагностика 30–40 минут один раз.
Уже занимаемся → диагностика как второе мнение, бесплатно.
Подумаю → мягко резервируем место, места расходятся.
