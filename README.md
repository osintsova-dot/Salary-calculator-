# Калькулятор ЗП · Speak&Smile

Считает зарплаты педагогов, администратора и отработки, показывает реальные
деньги месяца и остаток. Данные берутся из BigBen CRM.

Открывается по адресу **osintsova-dot.github.io/Salary-calculator-/**
Сборки нет: как файлы лежат, так и работают. `git push` в `main` = выложено
(GitHub Pages обновляет страницу за 1–3 минуты).

## Страницы

| файл | что это |
|---|---|
| `index.html` | сам калькулятор: выручка, педагоги, фиксированные выплаты, касса, остаток |
| `otrabotki.html` | отработки: обзвон, оплата Инге, сводка недели, картина месяца |
| `newcomers.html` | новенькие: кто заведён в CRM с мая, дошёл ли до группы, платит ли |
| `budget.html` | бюджет семьи (отдельное приложение, живёт своей жизнью) |

## Откуда данные

**Воркер `ss-bb`** — `~/salary-worker/worker.js`, деплой `npx wrangler deploy`.
Ходит в CRM под логином школы, хранит снимки в KV и отдаёт их страницам.

**Закладки в браузере** (то, что CRM не отдаёт воркеру — только живому браузеру):
- «⬇️ BigBen → калькулятор» — выручка по группам;
- «💳 BigBen → оплаты» — счета, возвраты, составы групп, способ оплаты.

Закладки собираются самой страницей: если код закладки менялся, её надо
**перетащить заново**, иначе она соберёт данные по-старому.

**Автосбор** — GitHub Actions в репозитории `speak-smile-hub`
(`~/speak-smile-hub/deploy/.github/workflows/otrabotki.yml`), четыре раза в сутки:
вход в CRM → выручка → финансы → отработки → длительность отработок → картина месяца.

## Как считается

- **Педагоги** — 25% от выручки группы, отпускные депозитом сверху.
- **Выручка** — по абонементам из CRM, а не по числу уроков. Скидки за длинный
  абонемент и раннюю оплату вычитаются в группе ребёнка.
- **Администратор** — 5% от выручки (плюс возвращённые скидки), но не ниже
  минимума. С сентября 2026 минимум 95 000 ₽. Порог, с которого процент
  обгоняет минимум, показан прямо в карточке.
- **Отработки** — Инге 25 ₽ за минуту фактического урока: время она ставит
  в мобильном приложении, оно доходит до CRM, воркер читает его из расписания.
- **Касса** — что реально пришло: помесячные счета отдельно от долей годовых
  абонементов, оплаченных весной.

## Проверки перед выкладкой

В `_стенд/` лежит headless-прогон страницы на настоящих данных: он открывает
собранную копию в Chrome без окна и печатает ключевые суммы. Правило простое —
любое изменение, которое двигает деньги, сначала показывается как «было / стало»
в рублях, и только потом уходит в `main`.

```
_стенд/обновить-данные.sh                      # свежие снимки из воркера
node _стенд/mk.js index.html 2026-09 /tmp/a.html && node _стенд/run.js /tmp/a.html
```

Папка `_стенд/` намеренно не в гите: на сайт она не выкладывается.
